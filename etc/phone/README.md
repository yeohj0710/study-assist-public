# 휴대폰 학습 보조기 실습

## 이미 설치한 폰에서 사용

1. 폰에서 **학습 보조기**를 엽니다. 렌즈 정보는 **설정**에서 확인합니다.
2. 폰 화면 쪽을 책이나 태블릿으로 향하고 한 쪽이 미리보기 대부분을 채우게 맞춥니다. 작은 미리보기를 누르면 중앙에 초점을 다시 맞춥니다. **설정 → 진동 시험**에서 3번, 보기 ④를 느껴 봅니다.
3. **촬영 시작**을 누르면 새 장면에서는 3초, 같은 장면에서는 6초 간격으로 찍습니다. 거의 같은 장면은 원본 대신 확인 신호를 보내며, 1분마다 원본을 다시 보냅니다. 화면이 보일 때는 폰 밝기 설정을 따릅니다. 가로에서는 미리보기 옆에, 세로에서는 미리보기 아래에 진행 기록이 나옵니다.
4. **촬영 중지**를 누르면 새 사진 전송을 멈춥니다. 노트북은 받은 사진을 계속 판별합니다. 남은 답을 기다리는 동안 **촬영 계속** 또는 **화면 끄기**를 누를 수 있습니다. 앱을 닫았다가 다시 열면 남은 답을 확인합니다. **다시 촬영할 문항**이 나오면 해당 지문과 보기를 다시 비추세요.
5. **진행 기록**을 위로 스크롤하면 앞 기록을 50줄씩 불러옵니다. **최신으로**를 누르면 맨 아래로 돌아갑니다. **받은 사진**은 가로 세 열, 세로 두 열로 엽니다. 상세에서는 **더 오래된 사진**, **더 최근 사진**으로 이동합니다. 휴대폰의 뒤로 가기를 누르면 사진 목록으로 돌아갑니다.
6. **화면 끄기**를 누르면 OLED 화면이 검게 표시되고 시스템 바가 숨습니다. 촬영과 답 수신은 이어집니다. **볼륨 올림 → 내림 → 올림 → 내림**을 4초 안에 짧게 누르면 앱 화면으로 돌아갑니다. 전원 버튼으로 폰을 잠그면 촬영은 멈춥니다.

## 받은 사진 확인

- **폰**에서 **받은 사진**을 누르면 최근 30장이 먼저 보입니다. 더 오래된 사진도 이어서 불러올 수 있습니다. 사진을 누르면 크게 열립니다. 두 손가락으로 확대하고 **목록으로** 또는 뒤로 가기를 눌러 돌아갑니다.
- **PC**에서 실행할 때 터미널에 표시하는 **받은 사진 폴더**를 엽니다.
- PC는 새 지문, 보기, 답 표시 또는 이어지는 조각을 확인한 사진만 보관합니다. 구도를 잡는 동안 잠시 띄운 미리보기는 문항 정보가 없으면 판별 뒤 내립니다. 파일명 앞부분은 노트북이 받은 날짜와 시각입니다.
- 메인 화면에 **세로**, **가로**, **자동**이 표시됩니다. 반대 방향은 **설정 → 화면 방향 상세**에서 고릅니다.

## 노트북에서 처음 실행

Windows에 Python 3.10 이상, Pillow, 로그인된 Codex CLI가 필요합니다. 실제 풀이는 로그인된 Codex 구독으로 실행합니다. 학습 사진은 모델로 전송됩니다. Windows에서 이 폴더의 PowerShell을 엽니다.

```powershell
python -m pip install Pillow opencv-python-headless
powershell -NoProfile -ExecutionPolicy Bypass -File ./start_phone.ps1 -Demo
```

처음 시작할 때 **connection.key**가 생깁니다. 개인 폰 설정에만 복사합니다. `-Demo`는 예제 17번의 답 ③을 보냅니다. 실제 풀이에서는 이 옵션을 빼고 시작합니다. PC가 태블릿이나 책의 영역을 찾으면 그 부분을 확대해 GPT-6.1 Sol에 보냅니다. 저장한 JPEG 원본은 그대로 확인할 수 있습니다. 사진 판별과 각 풀이 요청은 새 세션에서 실행합니다.

`-AgentRouter` 옵션을 붙이면 AgentRouter로 실행합니다. 내 키를 해당 PowerShell 창의 환경 변수 `AGENTROUTER_API_KEY`에 설정합니다. Codex 사용 한도에 도달할 때도 이 키가 설정돼 있으면 AgentRouter로 이어서 처리합니다.

### 무선 디버깅 연결에서 시험

이미 페어링한 기기에 ADB가 연결된 뒤, 아래를 입력합니다. 기기가 여럿 연결되면 adb 바로 뒤에 `-s 내_휴대폰_주소`를 넣습니다. ADB가 다시 연결되면 역방향 연결도 다시 설정해야 할 수 있습니다.

```powershell
adb install -r ./학습보조기.apk
adb reverse tcp:8786 tcp:8786
```

PC에서 **http://127.0.0.1:8787**을 열어 서버 상태를 확인합니다. 휴대폰 주소는 다음 단계의 Tailscale 주소를 씁니다.

### 밖에서 사용

1. [Windows Tailscale](https://tailscale.com/docs/install/windows)과 [Android Tailscale](https://tailscale.com/docs/install/android)에 같은 개인 계정으로 로그인합니다.
2. 노트북 PowerShell에서 서버를 켜 둡니다. 이미 실행 중이라면 이 명령은 건너뜁니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./start_phone.ps1
```

3. 두 번째 PowerShell에서 Tailscale 사설망으로 로컬 서버를 전달합니다. 같은 PC에서 최초 한 번만 실행합니다.

```powershell
$ts = Join-Path $env:ProgramFiles 'Tailscale/tailscale.exe'
& $ts ip -4
& $ts serve --bg --tcp=8786 tcp://127.0.0.1:8786
& $ts serve status
```

4. 폰의 **설정**에 노트북 Tailscale 주소와 연결 키를 넣고 **연결 확인**을 누릅니다. **노트북에 연결했습니다**가 나오면 저장합니다. 주소는 `http://`, 위 명령에서 나온 IP, `:8786` 순서로 입력합니다.
5. 폰 Wi-Fi를 끄고 LTE 또는 5G에서 사진을 보냅니다. 전송 장수가 늘어나면 **받은 사진**에서 원본을 확인합니다. 외부 사용 중에는 노트북을 전원에 연결하고 절전에 들어가지 않게 합니다.

공개 저장소의 [연습 자료](../../examples/README.md)에서 자체 제작 예제와 공식 기출 링크를 확인하세요.

## 답 알림

- **답 도착**은 짧게 두 번으로 시작합니다. 답은 풀이가 끝난 순서로 한 번씩 전달합니다. 쪽을 넘겼어도 바로 대기열에 넣고, 앞의 진동이 끝나면 보냅니다. 놓친 답은 폰의 **진행 기록**과 PC의 **지금 진행**에서 확인합니다.
- 짧게 **0.14초**, 길게 **0.62초**입니다. 묶음 안은 **0.24초**, 다음 자리 앞은 **0.8초**, 보기 앞은 **1.5초** 쉽니다.
- **17번 답 ③**은 `●● / ● / ▬●● // ●●●`입니다. `/`는 0.8초, `//`는 1.5초 쉼입니다. 보기 앞에서 가장 길게 쉰 뒤 울린 짧은 횟수를 세세요.
- **여러 사진에 나뉜 문제**는 왼쪽 열에서 오른쪽 열, 또는 다음 쪽 순으로 최대 여덟 장을 풀이에 보냅니다. 번호가 빠진 같은 쪽 사진은 실제 글씨가 겹치는지 확인합니다. 지문 가운데나 마지막 보기가 어느 사진에도 없으면 보류합니다.
- **한 장에서 푸는 문항**은 지문과 마지막 보기까지 읽혀야 풀이를 시작합니다. 다음 문항 일부가 프레임에 걸치면 그 문항은 사진을 더 기다립니다.
- **진동 파형**은 앱이 Android에 요청한 시간에 맞춰 움직입니다. `●`는 짧게, `▬`는 길게입니다. **마지막 진동 요청**에는 앱이 보낸 마지막 신호가 표시됩니다. 착용 상태에서 느껴지는 세기는 **설정 → 짧게와 길게**, **17번 답 ③ 시험**에서 확인하세요.
- **다시 촬영**은 `▬▬` 뒤에 문항번호가 옵니다. 알려진 문항 또는 앞뒤 번호 사이의 빠진 번호를 알립니다. 번호를 찾지 못한 장면은 `▬▬`만 옵니다. 촬영을 중지해도 대기 중인 판별과 풀이가 끝날 때까지 앱을 열어 두세요.
- **내 답 확인**은 `▬●` 뒤에 문항번호, 1.5초 쉼, 풀이 답이 옵니다. 한 보기에 체크하거나 문항번호 옆에 1~5를 한 숫자로 씁니다. 서로 다른 두 장에서 같은 선택을 읽고 풀이 답과 다르면, 같은 문항과 표시한 답의 조합에 한 번 알립니다. 두 표시가 서로 다르거나 흐리면 답이 틀렸다고 알리지 않습니다.
- **끝 번호 확인**은 `설정 → 확인할 문항 범위`에 `1-10`처럼 입력하고 저장하세요. 촬영을 시작하면 이 범위를 기준으로 처음과 끝에서 안 잡힌 번호도 대조합니다. 다른 교재로 바꿀 때는 새 촬영을 시작하고 범위를 바꾸거나 지우세요.

## 영어 듣기 연습

개인 연습용 음원과 문항별 시간표를 노트북에 둡니다. `windows.csv` 첫 줄은 `question,start,end`입니다. 예를 들어 `7,1.5,18.2`는 음원 1.5~18.2초를 7번과 연결합니다. 공통 지문은 해당 문항 구간에 함께 넣습니다.

```powershell
python -X utf8 ./listening_source.py --audio ./practice.wav --windows ./windows.csv --output ./listening.json
./start_phone.ps1 -ListeningTranscript ./listening.json
```

첫 명령은 설치된 `faster-whisper`, PyAV와 캐시된 Whisper 모델로 음원을 로컬 변환합니다. 만들어진 자막에서 문항번호와 보기 순서를 확인합니다. 두 번째 명령은 해당 자료를 사용하는 촬영 서버를 시작합니다. 폰으로 같은 교재의 번호를 비추면 노트북이 그 번호의 자막을 사진과 함께 풉니다. 마이크 대신 파일을 입력합니다. 일반 문제로 돌아갈 때는 `-ListeningTranscript` 옵션을 빼고 서버를 시작합니다.

기본 서버는 Codex 구독을 쓰고, 사용 한도를 확인했을 때만 저장된 AgentRouter 연결로 넘어갑니다. 두 경로가 소진되면 받은 사진을 남기고 판별 또는 풀이를 보류합니다.

## 실제 확인 범위

갤럭시 S25 울트라 SM-S938N의 전면 렌즈는 화면 상단 가운데입니다. **카메라 ID 1, 3.3mm**, **4000×3000 JPEG**와 중앙 연속 자동초점을 확인했습니다. Tailscale을 거쳐 폰에서 서버의 인증 응답까지 확인했습니다. 실제 교재 촬영, 소음, 외부 모바일 데이터 연결과 배터리는 PDF 순서대로 확인합니다.

## PC 진행 화면과 장시간 사용

- 서버와 같은 PC에서 http://127.0.0.1:8787/ 을 엽니다. 작업 대기열과 문항별 진행, 풀이 근거, 폰 배터리와 발열, 사진 저장량을 확인합니다.
- 받은 사진은 PC에 저장합니다. 대놓고 문제지가 아닌 장면은 걸러냅니다. 보관본은 긴 변을 2,400픽셀 이하로 줄입니다. 보관 한도는 2 GiB입니다. 보류한 사진을 먼저 정리하고, 같은 우선순위에서는 오래된 사진부터 지웁니다.
- 폰의 **설정 → 모델 설정**과 PC 화면에서 **빠르게**, **균형**, **정밀**을 고릅니다. 판별 모델과 풀이 모델을 Sol 6.1, Terra 6.1, Luna 6 중에서 따로 고를 수도 있습니다. 바꾼 설정은 다음 모델 호출부터 적용합니다. 동시 판별은 대기 시간이 중요할 때 켭니다. 모델 호출이 늘 수 있습니다.
- 촬영 중이나 남은 답을 기다릴 때도 설정에서 주소와 키를 확인할 수 있습니다. 저장은 연결 없이 가능합니다. 주소나 키를 바꾸면 새 촬영으로 시작합니다.
- 폰에서 진행 기록을 비우면 폰에 표시된 기록이 먼저 사라집니다. 노트북에 연결돼 있으면 노트북 기록도 비웁니다. 받은 사진과 진행 중인 풀이는 남습니다.
- 과목을 바꾸면 확실히 확인한 과목명과 지문을 바탕으로 같은 번호를 구분합니다. 새 시험을 시작할 때는 이전 응답 확인을 마친 뒤 새 촬영으로 시작합니다.
- 12시간 실측에는 전원을 연결한 폰과 절전에 들어가지 않는 Windows PC가 필요합니다. 촬영을 시작한 뒤 앱의 화면 끄기를 사용합니다. Android가 심한 발열을 보고하면 촬영 간격을 늘리고 답 확인은 계속합니다.
